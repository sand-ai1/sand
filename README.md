## What is SAND?

SAND is a **self-evolving personal AI agent OS** that runs entirely on your machine.

- **One entity, eight modes** — code, design, security research, deep research, computer control, automation, life management, voice — one brain, one personality
- **A brain that evolves** — SAND learns from your real experience every week and updates its own weights (eval-gated, rollback-able, yours to inspect)
- **Local-first privacy** — your model, your memory, your encryption keys. Nothing leaves your machine unless you ask
- **Zero-refusal for your own assets** — built for owners who test what they own
- **Works for everyone** — from an old laptop (SAND Lite) to a 24GB GPU (SAND Ultra)

## Install

**macOS / Linux:**
```bash
curl -fsSL https://sand.so/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://sand.so/install.ps1 | iex
```

One command. Everything auto-detected. Three questions max. Clean uninstall with `sand --uninstall`.

## Hardware Tiers

| Tier | Hardware | Brain |
|---|---|---|
| Lite | Any 2016+ machine, 8GB RAM | SAND Micro (CPU) |
| Standard | 16GB RAM, 6GB VRAM | SAND Core |
| Pro | 12-16GB VRAM | SAND Prime (full agent) |
| Ultra | 24GB VRAM | Everything + overnight self-training |
